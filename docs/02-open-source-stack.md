# 01. 项目概览

## 1. 项目愿景

本项目的目标是：

- 让用户只提供剧本
- 系统自动生成完整 AI 漫剧短片
- 最终输出可播放的 MP4

## 2. 现实可行度

这个目标可以做，但不能追求“一个神经网络直接输出完整长篇动画”。真正可行的方案是：

- 人工输入剧本
- 模型负责结构化、分镜、生成图像和语音
- 工具负责拼接、剪辑和导出

## 3. 核心流程

```text
剧本输入
  ↓
剧本解析（剧情分场）
  ↓
分镜脚本生成
  ↓
角色卡生成
  ↓
镜头图像生成
  ↓
TTS 配音
  ↓
背景音乐 + 音效
  ↓
FFmpeg / MoviePy 合成视频
  ↓
输出 MP4
```

## 4. 关键难点

### 4.1 角色一致性

不同镜头中，同一个角色必须保持一致的：

- 外貌
- 服装
- 语音风格
- 表情

### 4.2 景别和镜头连续性

镜头之间需要有逻辑顺序，不能随机切换。

### 4.3 配音同步

对话要和画面时长匹配，否则会显得很僵。

## 5. MVP 目标

最小可行版本只做：

- 1 个剧本
- 3-5 个场景
- 每个场景 3-5 个镜头
- 每个镜头 1 张图
- 完整配音和剪辑
- 输出 2-5 分钟短片

## 6. 设计原则

- 先做能跑，不要一开始追求完美
- 先用 API 快速验证，再做本地部署
- 先有完整链路，再慢慢优化细节

## 7. 结论

这个项目可以做成一个真正的 AI 剧情视频生成器，但需要把它分成多个模块逐步实现。
