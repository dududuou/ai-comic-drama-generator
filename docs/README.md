# 05. MVP 功能清单

## 必做项（最小可行版）

- [ ] 用户上传剧本
- [ ] 解析剧本成 scenes
- [ ] 每个 scene 生成多个 shot
- [ ] 每个 shot 生成图片
- [ ] 每段对白生成 TTS
- [ ] 拼接成短视频
- [ ] 输出最终 MP4

## 进阶项

- [ ] 角色卡统一
- [ ] 镜头风格统一
- [ ] 语音情绪控制
- [ ] 自动字幕
- [ ] 音乐与音效
- [ ] 前端任务看板

## 质量验收标准

- 画面能看
- 角色风格基本一致
- 配音和字幕基本同步
- 整体剧情可理解
- 最终输出可播放

## 完成门槛

如果你能跑通下面这条链路，说明 MVP 完成：

```text
剧本文本 -> 结构化 scenes -> 生成 shot -> 生成 image -> 生成 TTS -> 输出 video
```

这个链路跑通后，后续再做性能、角色一致性和长期剧情管理。

## 最终目标

不是做一个完美长篇动画，而是做一个可运行、可演示、可扩展的 AI 漫剧生成原型。
